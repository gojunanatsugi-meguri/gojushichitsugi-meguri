# 現地確認リスト（QR・クイズ担当）

アプリ側（QR読取・スタンプ・クイズ・クーポン選択）は仮データで動く状態になっている。
本番（1月27日）までに、現地と協力店で次のことを確かめ、`lib/models/app_state.dart` のデータを差し替える。

### ⚠ 本番の日に営業しているか

枚方凍氷のかき氷は **4月上旬から約6か月の期間限定**（京阪電車の紹介ページでは「営業は10/12まで」）。
**1月27日は営業していない可能性が高い。** 店が開いていないと、QRを読めず、クーポンも使えない。
→ 店に冬の営業を確認し、営業していなければ、第1地点の協力店を変えるか、店の外にQRを貼らせてもらえるか相談する。

ほかの店についても、**1月27日（水）の営業日・営業時間**を確認する。

## 2. 協力店にお願いすること

- [ ] QRコードを貼る場所（外から読めるか、高齢の方の目の高さか、店内は明るいか）
- [ ] **確認番号（4桁）**を伝え、「位置がずれてスタンプが取れないお客さんが来たら入力してください」とお願いする
      （印刷物の「店員さん用の説明」に番号と使い方が書いてあるので、それを渡せばよい）
- [ ] クーポンの内容と、使い方（画面を見せるだけでよいか）
- [ ] 発行できるクーポンの上限があるか

## 3. クイズを作る（答えは「次の地点の周辺」に置く）

今アプリに入っている問題は仮。歩きながら次の点を確かめて、問題とヒントを決める。

- 答えが **歩きながら目で見て確かめられる** ものか（看板・石碑・のれんの文字など）
- 選択肢は3つ。高齢の方が読める長さか
- ヒントで答えに近づけるか（ヒントは誰でも見られる）

案（すべて要現地確認）:

| 出題する地点 → 答えがある地点 | 問題案 | 確かめること |
| --- | --- | --- |
| 第2地点 → 第3地点（呼人堂） | 次の地点のどら焼き屋さんは、いつから続くお店？（明治／昭和／平成） | 店の看板やのれんに創業の年が書かれているか |
| 第2地点 → 第3地点（呼人堂） | 次の地点のどら焼き屋さんの、看板商品の名前は？ | 店頭で名前が見えるか |
| 第4地点 → 第5地点（巴堂） | 次の地点で売られている、枚方名物のお餅は？（今の仮の問題） | 店頭に「くらわんか餅」と書かれているか |
| 〜 → 枚方凍氷 | 次の地点のお店は、もともと何を売るお店だった？（氷／お米／お茶） | 店の外から「氷屋」とわかる表示があるか |

## 4. 本番用のQRコード

- [ ] 協力店と地点が決まったら、QRの値（`qrValue`）と確認番号（`staffPin`）を作り直す
